How this page handles your text

  • Identifiers are replaced with [REDACTED] in the browser before anything is sent.
  • Redacted text is sent once to /api/stc-request on this site. The server redacts again and withholds the text entirely if it still appears to identify a patient. It is classified by TypeSafe, a third-party AI service.
  • Only redacted text is ever shown, stored or logged.
  • The log records the redacted request, never what was removed or how many.
  • Security and data handling

Prove it

Runs in this page with no network. It uses clearly labelled synthetic test samples (not real patients), passes them through every text gate, then checks that none of them appear in the page state, the activity log or localStorage. The samples are discarded afterwards.
